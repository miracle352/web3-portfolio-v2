# IYAN Portfolio

A lightweight, responsive portfolio for Iyanuoluwa, a Lagos-based Web3 community and growth operator.

## Run locally

```bash
python -m http.server 4173
```

Open `http://localhost:4173` in a browser.

## Personal details to update

- Replace `hello@iyan.fun` in `index.html` with the preferred contact address.
- Add any verified social links or selected project work when they are ready to publish.

The site has no build step or dependencies.
